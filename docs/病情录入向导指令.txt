# 病情录入向导指令（粘贴到 Codex 新对话）

使用 health-condition-tracker 技能，按以下顺序帮我走一遍「病情录入向导」：
1. 如果还没开启多家人档案，先问我是否开启；
2. 问我本次症状（可多个）、严重程度（1-10）、发病日期、持续时长、备注；
3. 问我是否需要补充之前更早的病情（需要的话帮我回填真实发病日期）；
4. 根据我的症状追问 2-3 个相关问题（部位、诱因、伴随症状、缓解方式、检查用药等）；如果一次补录较多，追问总量控制在 9 题以内，避免问太多；
5. 开启多家人档案时，问我本次病情添加到哪个档案（已有档案 / 新建 / 默认）；
6. 保存记录后，用 scripts/intake.py 或 scripts/charts.py 给出可视化分析摘要；
7. 问我是否生成病情视图报告（HTML），需要就运行 scripts/condition_report.py --member <名字>。
最后附免责声明。

也可以在终端直接运行：
    cd D:\codex-skills\health-condition-tracker
    python scripts\intake.py
