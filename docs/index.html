病情录入向导（对话版）

让 Codex 在对话里按向导流程提问：多档案 → 症状 → 补充既往 → 追问 → 选档案 → 可视化 → 视图报告。

使用 health-condition-tracker 技能，按以下顺序帮我走一遍「病情录入向导」：
1. 如果还没开启多家人档案，先问我是否开启；
2. 问我本次症状（可多个）、严重程度（1-10）、发病日期、持续时长、备注；
3. 问我是否需要补充之前更早的病情（需要的话帮我回填真实发病日期）；
4. 根据我的症状追问 2-3 个相关问题（部位、诱因、伴随症状、缓解方式、检查用药等）；
5. 开启多家人档案时，问我本次病情添加到哪个档案（已有档案 / 新建 / 默认）；
6. 保存记录后，用 scripts/intake.py 或 scripts/charts.py 给出可视化分析摘要；
7. 问我是否生成病情视图报告（HTML），需要就运行 scripts/condition_report.py --member <名字>。
最后附免责声明。

常用命令（先在终端 cd 到 D:\codex-skills\health-condition-tracker）

病情录入向导（交互）

一问一答录入：多档案开关 → 症状 → 补充既往 → 追问 → 选档案 → 可视化 → 视图报告。

python scripts\intake.py

快速录入病情

一条命令保存症状，自动可视化，加 --report 生成视图报告。

python scripts\intake.py --symptom 头痛 --severity 6 --member 妈妈 --report

开启多家人档案

开启后每次录入会询问「添加到哪个档案」；用 --disable-multi 关闭。

python scripts\intake.py --enable-multi

查看已有档案

列出多家人档案开关状态与已有成员。

python scripts\intake.py --list-members

病情视图报告

生成自带图表的 HTML 报告（时间线 + 统计 + 图表 + 用药 + 治疗方案）。

python scripts\condition_report.py --member 妈妈

间隔期总览

隔几周回来，一条命令看全家要点。

python scripts\snapshot.py --all-members

记录症状（今天）

给某位成员补录症状。

python scripts\symptom_log.py --symptom 头痛 --severity 6 --member 妈妈

记录症状（回填发病日期）

隔几周补录时填真实发病日期。

python scripts\symptom_log.py --symptom 咳嗽 --severity 5 --date 2026-08-10 --member 妈妈

复诊 / 停药提醒

列出 14 天内复诊与停药提醒（含逾期）。

python scripts\reminders.py --all-members --days 14

趋势分析

症状频率与严重程度趋势。

python scripts\trend_analysis.py --member 妈妈

图表可视化

症状频次 / 严重程度 / 体征趋势 PNG（需 matplotlib）。

python scripts\charts.py --member 妈妈

日历热力图

按月症状严重程度热力图（需 matplotlib）。

python scripts\calendar_heatmap.py --year 2026 --month 9 --member 妈妈

联网搜索

多引擎交叉验证（DuckDuckGo/Bing/Mojeek/维基），官方来源优先。

python scripts\web_search.py "偏头痛 治疗"

OCR 读图

从化验单 / 照片提取文字（需 Tesseract）。

python scripts\image_processor.py "图片路径.png"

医生沟通报告

生成 Markdown 就诊报告。

python scripts\report_generator.py --member 妈妈

用药管理

添加 / 查看 / 删除用药记录。

python scripts\medication_tracker.py add --name 布洛芬 --dosage 400mg --frequency 每日2次 --member 妈妈

治疗方案

保存诊断、建议、复诊时间。

python scripts\treatment_plan.py add --diagnosis 高血压 --advice 按时服药 --follow-up 2026-09-05 --member 妈妈

建议科室查询

按成员近期症状推荐就诊科室（就诊前用）。

python scripts\departments.py --member 妈妈

一键备份全家数据

全家数据打包 zip（JSON + CSV + 图表），CSV 可用 Excel 打开。

python scripts\export_data.py --all-members

病情视图报告（带备注）

在报告「建议下一步」里追加备注。

python scripts\condition_report.py --member 妈妈 --note "建议检查血常规和血压"

就诊意见 + 十大医院

按成员症状推荐全国十大医院，结合患者城市给就诊方案（把城市换成实际城市）。

python scripts\analyze.py 头痛 发热 --quiz --web

难受程度客观评估

快速版只问 3 个问题、全部可留空跳过；需要更细用 --full（每项也可跳过）。结果存成员档案。

只看官方来源搜索

只显示政府/卫健委/疾控/WHO/PubMed等官方权威来源。

报告单/体检单解读

OCR 化验单/体检单/CT报告文字 → 异常标记 + 危急值提醒 + 与上次对比（CT影像原图请以放射科报告为准）。

python scripts\lab_analyzer.py "报告单.jpg" --member 妈妈 --compare

长期病程分析（客观校准）

按病程和趋势客观校准：慢性稳定自动降级不吓人，加重才升级。

python scripts\analyze.py 腹痛 --severity 6 --duration 2个月 --trend 平稳 --member 妈妈

国际权威就诊路径

按 NHS/Mayo/CDC/WHO 指南给出分档就诊路径（家庭观察→门诊→近期→尽快→急诊）。

python scripts\analyze.py 腹痛 --severity 6 --duration 2天 --trend 平稳 --member 妈妈
