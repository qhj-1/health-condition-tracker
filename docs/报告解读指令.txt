# 报告单解读指令（粘贴到 Codex 新对话）

使用 health-condition-tracker 技能，帮我解读这份报告：
1. 上传报告单图片或粘贴文字；
2. 图片用 scripts\lab_analyzer.py "图片路径" --member <名字> --compare；
3. 给我：
   - 识别到的项目数量、异常项目（↑/↓）、危急值（如有，先提醒我就医）；
   - 异常指标的可能意义（保守表述，不吓人）；
   - 与上次报告的对比（新增异常 / 已恢复）；
   - 建议复查或就诊的科室；
   - 报告存档位置；
4. 如果是 CT/MRI 影像原图：明确告知我不能替代放射科医生判读，建议带原片就诊。
最后附免责声明：解读基于通用参考范围，以报告单和医生意见为准。
