# 国际权威就诊路径指令（粘贴到 Codex 新对话）

使用 health-condition-tracker 技能，按国际权威指南（NHS / Mayo Clinic / CDC / WHO）
为以下症状给出「就诊路径」，不要一刀切：
症状：<症状>；严重程度：<1-10>；病程：<如 3天/2个月>；趋势：<好转/平稳/加重>

要求：
1. 运行 scripts\analyze.py <症状> --severity <分> --duration <病程> --trend <趋势>；
2. 先给「病程判断」和「风险分级」（保守筛查，不吓人）；
3. 再给「就诊路径」：家庭观察 / 预约门诊 / 近期就诊 / 尽快就诊 / 立即急诊，
   并说明时间窗、该症状的升级条件（出现哪些情况要升级）、以及依据来源（NHS/Mayo/CDC/WHO 网址）；
4. 长期慢性且稳定的症状按原计划复诊即可，不要因为程度数字高就吓人；
5. 命中真紧急症状（呼吸困难、意识模糊、严重出血等）才明确立即就医。
最后附免责声明。
