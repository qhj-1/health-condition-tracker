# 难受程度评估指令（粘贴到 Codex 新对话）

使用 health-condition-tracker 技能，帮我快速评估难受程度（不用问太多）：
1. 运行 scripts\severity_quiz.py（默认快速版）；
2. 只问这 3 个问题，都可以留空跳过：
   - 最近最明显时不适有多强？（0-10，按锚点：5=做事效率下降需休息 / 8=必须停下 / 10=无法忍受）
   - 是否影响睡眠/工作/饮食？（如：影响睡眠）
   - 和之前比？（好转/平稳/加重/快速恶化）
3. 再问一句紧急警示：有没有呼吸困难、胸痛胸闷、意识模糊、严重出血、剧烈到无法忍受？（有则立即就医）
4. 给我综合分和等级（未填强度就说明“未评级，建议简单自评”）；
5. 需要更细时再用完整版：python scripts\severity_quiz.py --full。
最后附免责声明。
