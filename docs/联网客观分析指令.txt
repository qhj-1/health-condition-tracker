# 联网客观分析指令（粘贴到 Codex 新对话）

使用 health-condition-tracker 技能，对以下症状做「病情分析 + 联网资料摘要」：
症状：<症状，如：头痛 发热>
严重程度（1-10）：<可填>

要求：
1. 先运行 scripts\analyze.py <症状> --severity <分数> --web；
2. 先给我「客观分析」：风险分级（低/中/中危/紧急）、可能疾病（按高度相关/可能相关分层）、建议科室、建议行动；
3. 再单独给我「联网资料摘要」：列出搜索来源（标题+网址+摘要），并明确标注这些内容仅供参考、可能过时或含广告；
4. 强调：分析结论在联网搜索之前已经得出，只基于本地知识库和我的描述，不会被网络信息带偏；
5. 命中紧急症状时，先提醒我就医，不要因网络资料改变就医决定。
最后附免责声明。
